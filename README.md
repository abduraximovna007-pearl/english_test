# Ingliz Tili Testi – 1-kurs 🇬🇧

Bu loyiha 1-kurs talabalari (yoki ingliz tilini o'rganuvchilar) uchun mo'ljallangan interaktiv va zamonaviy **Ingliz tili testi** veb-ilovasidir.

## Loyiha haqida
Ilova juda tez ishlaydi va hech qanday server talab qilmaydi (to'liq brauzerda ishlaydi). Zamonaviy qorong'u (Dark mode) dizaynda yozilgan bo'lib, test ishlash davomida foydalanuvchining ko'zini charchatmaydi. Ilova ichida to'g'ri javoblarni hisoblash, jarayon chizig'i (progress bar) kabi ajoyib xususiyatlar mavjud.

## Asosiy imkoniyatlari
- **Bitta fayl arxitekturasi:** Barcha tuzilma (HTML), dizayn (CSS) va mantiq (JavaScript) yagona `index.html` faylida yozilgan (Standalone).
- **Zamonaviy UI/UX:** Chiroyli gradient ranglar, yumshoq animatsiyalar, Google Fonts (`Playfair Display`, `DM Sans`) yordamida yaratilgan chiroyli tipografiya.
- **Darhol natija:** Variantni tanlaganingiz zahoti, uning to'g'ri yoki noto'g'riligini aniq ranglarda (yashil/qizil) ko'rsatadi.

## Qanday ishga tushiriladi?
Hech qanday murakkab dasturlar yoki kutubxonalar o'rnatish shart emas.

1. Loyihani klon qiling (yuklab oling):
   ```bash
   git clone https://github.com/abduraximovna007-pearl/english_test.git
   ```
2. Papka ichiga kiring.
3. `index.html` faylini Google Chrome, Firefox yoki Safari kabi istalgan brauzerda oching.
4. Va testlarni ishlab, bilimingizni tekshiring!
